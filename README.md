### Featured Projects

#### [poisson-accident-modeling](https://github.com/maximussec/poisson-accident-modeling)

**Statistical modeling and analysis of severe traffic accidents on the BR-101/AL highway.**

A reproducible Python pipeline that processes real-world PRF DATATRAN 2025 data, filters and transforms the dataset, classifies observations, estimates Poisson parameters, and performs Pearson's Chi-Square goodness-of-fit testing.

`Python` `Pandas` `NumPy` `SciPy` `Matplotlib` `Applied Statistics`
